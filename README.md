# Sync AI LaunchPad

Sync AI is a **multichain token launchpad website** built for the **Reown Appkit Bounty**.

This repository contains the full codebase for the **Sync AI web application**, which serves as the primary interface for creating, managing, and exploring token launches across multiple blockchain networks.

---

## Overview

* Web-based interface for a multichain token launchpad
* Focused on usability, performance, and clean UI architecture
* Designed to integrate seamlessly with blockchain SDKs and onchain workflows

This project demonstrates:

* Building real-world Web3 product frontends
* Translating complex blockchain concepts into usable interfaces
* Structuring a production-ready Next.js application

---

## Tech Stack

* Framework: **Next.js**
* Language: **TypeScript**
* Styling: **Tailwind CSS**
* Deployment: **Vercel**
